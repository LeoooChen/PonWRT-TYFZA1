# Wi-Fi 下行研究：合入 main 的有效改进

本次将旧 main `9331c6e` 上研究并保留的产品改动适配到 main `eb83341`。
仅合入下列四项及其必要验证，不迁移实验开关、参数扫描或完整实验日志。
研究分支为 `fix/wifi-downlink-root-20261107`，完整证据保留到 `9e5bf7c`。

## 1. 受 preload 保护的长度边界处理

来源：`8ee15dc`，性能证据补充于 `4116f08`。

原来的 BK 是在长度下降时打断外层 A-MPDU 聚合，**不是截断或丢弃报文内容**。
它规避了 8852C 在特定大小帧混排时停止完成发送的问题；直接删除会重新暴露冻结。
原厂 per-peer preload 配置在 5/1、7/1 大小帧压力场景中避免了反复复现的冻结。
这支持采用 preload 规避该故障，尚不足以解释全部芯片内部原因或默认 TCP 上限。

产品实现为 8852C 配置固定 8 个专用、2 个通用 CAM 项，最多向四个 AP 客户端授予
preload 资格。先预留资格，再发送启用命令；命令超时仍保留资格，防止硬件已接受时超配。
离线清理先等待 NI 退出并完成硬件丢弃，再等禁用命令确认后释放资格。
只有成功启用的客户端允许跨越长度下降边界；其他客户端保留长度保护。
客户端/队列上下文切换、非 A-MPDU 报文的 BK 保持。

同一关联、普通桥接、Mac 默认 TCP 参数、默认单流 10 秒测试中，旧长度 BK
开/关/开为 **1.420421 / 1.483228 / 1.423603 Gbps**，关闭后约提高 **4.3%**。
同一 30 秒连接内切换的有效区间为 1.402076 / 1.461062 / 1.405689 Gbps，约提高 4.1%。
这些样本 NI 全部回收，failed/retired 为 0。该收益不能扩写成历史特殊负载的约 44% 收益。

## 2. 软件请求所有权与硬件 WP 标签分离

来源：`b60f848`，最终 BK 策略采用上述 `8ee15dc`，不单独采用中间版本的无条件删 BK。

按 DMA 通道维护硬件 tag 到软件请求的映射，使用独立的分配、完成及回收生命周期；
NI 请求池为 2048/1024，完成环为 4096，TX PE 共享 DDR 为 512 KiB。
提交、RPQ 回报、队列/标签回绕、缺少 EQ 回收额度时的重试均保持同一份报文所有权。
这是解耦与容量改进，未证明单独消除 TCP 瓶颈；代价是扩大元数据及相应分配空间。

## 3. 有界的 NI 批量接收

来源：`dc6c808`。

每轮最多发布八个 MPDU，先批量接收最多 64 个 MSDU，队列少于八个时提前补充。
共享队列统计及时间戳读取，仍然不等待新报文到达，并保留原有省电队列限制。
历史同一关联 UDP A/B/A 为 **1.844 / 1.903 / 1.845 Gbps**，支持小幅收益。

## 4. NI 组帧路径独立

来源：`386d89d`。

NI 自有 Ethernet 缓冲区直接生成最终 WLAN/A-MSDU 布局，移除重复的通用主机头处理。
主机 DMA 地址继续作为不可由 PE 解引用的地址使用。测试中最终 DMA 载荷逐字节一致，
原研究用例约减少 100 条执行指令；未观察到可归于该重构的独立吞吐提升。

## main 适配与验证

- main 的请求 word4 bit23 已用于 STA 地址格式；preload 改用 **word5 bit15**，
  使用共享常量，避免旧分支直接 cherry-pick 造成碰撞。
- preload 资格仅用于 8852C AP 客户端；STA/mesh 不授予资格。NI 组帧保留 main 的
  STA ToDS/BSSID/DA 地址语义，ARM 路径保留 mesh 头和发送成功率统计。
- 集成后的 ARM64 模块已针对包含 `CONFIG_MAC80211_MESH=y` 的已准备内核编译；
  PE_UPLINK 与直接路径均编译，并执行报文头及 IMEM/DMEM 检查。
- PE_UPLINK 镜像 25640 字节，保守栈上界 6848 字节，满足 32 KiB IMEM / 8 KiB DMEM。
  SHA256：`eb7c6b3cf0f08bf29a3b6f63b3968c71d4daa51a2daa7af7693d4f05313b8fd2`。
- 链接后真实 PE 指令测试覆盖混合长度、A-MSDU padding/SG/LS、AP/STA 地址、mesh raw 头、
  六通道提交、RPQ 回收、标签及完成环回绕、省电队列和退休边界。
  所有权压力覆盖 6144 次提交/2048 在途及 5120 次提交/1024 在途，含乱序完成和 EQ 额度失败。
- 原生 C 测试覆盖 preload 配额/超时/重试/释放、C 与 XB 初始化差异、AP/STA/mesh 资格边界、
  8448 组请求构造、站点/BA/密钥清理、STA 生命周期、mesh 同步和链路指标。
- 构建、测试原始输出保留于本地主仓库 `artifacts/downlink-main-integration/`。

## 边界与未达成项

实机证据来自旧基线研究固件；**本次适配后的 main 未重新加载到设备进行实机验收**。
此前五次重关联验证通过，但没有五个无线客户端同时连接的物理验证。
UDP 满负载仍有丢包，TCP 也有波动，不能声明无全部回归或已解决完整吞吐根因。
最终默认 TCP 确认轮约 **1.47–1.49 Gbps**，**1.7 Gbps 小目标和原双向 1.8/2.0 Gbps 目标均未达到**。
超频、Mac 窗口/ACK 调整、激进 EDCA、固定速率、强制 awake 等未作为产品修复合入。
本次仅提交代码和验证记录，不刷机、不推送，也不处理 main 原有启动问题。
